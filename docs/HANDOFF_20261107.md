Recovery (mean +- SD over 6 folds, rule D):
| | MSAss | Filtered |
|---|---|---|
| uniform prior / dG p0 alone | 73.3 / 91.7 | 80.8 / 96.1 |
| default MaxEnt (`maxent_convexKL_loss` = KL(uniform||w)), final states | 81.2 +- 7.3 | 82.2 +- 3.6 |
| KL(w||p0_dG) arm, final states, Adam as shipped | 93.0 +- 1.1 | 93.7 +- 4.8 |
| same with Adam inner step 0.1 (emulated in driver) | 93.8 +- 1.0 | 93.7 +- 4.8 |
| study solver (docs/recovery_gulf_20261103/selgci), same objective | 93.8 +- 1.0 | 93.7 +- 4.8 |

Pipeline findings, isolated by component:
- Objective: pipeline minimises 1000/(1+S_p)[S_p*L_sigma + KL]; S_p = 2S/H maps to the study's S
  (replays to 1e-4). The default MaxEnt is the reverse KL with uniform prior; it cannot express the recipe.
  The recipe direction is `maxent_reverse_KL_logp0_loss` in `jaxent/examples/common/losses.py`
  (new, uncommitted; changes the fitting-code hash so old manifests warn on replay), used via the
  existing `frame_regularizer` hook of `jaxent/examples/common/optimization.py`.
- Optimiser: inner Adam step is hard-coded 1.0 (`jaxent/src/opt/optimiser.py:131`); configured lr
  only pre-scales gradients. 27/198 MSAss recipe-arm runs sit at the optimum ~1900 steps then collapse
  to 1-5 frames. Inner step 0.1 fixes all 396 runs. Making it configurable is a `jaxent/src` change —
  user go-ahead pending.
- Candidate pool: convergence checkpoints are early snapshots (median step 62), `running_best`
  median step 3; selecting from final states only reproduces the study picks.
- Remaining gap to the published study numbers (93.1 / 94.9) is the lnPF floor max(lnPF+delta, 0),
  which k_int scaling cannot express.

### 8.1 aSyn pilot rerun with the recipe regulariser (done)
`fitting/_pilot_uptake_rkl_20261107/` (README.md, results_table.md, per-cell plots; 7.3 GB). Same driver with two
new opt-in flags: `--regulariser reverseKL` (KL(w||uniform) through the `frame_regularizer` hook) and
`--inner-adam-step 0.1` (emulated, as in the MoPrP driver); S grid 10-3162, 4/decade, set from a calibration
scan; 220 runs, 3.4 h at 9 jobs. Findings:
- ESS now declines smoothly with S (fold A 99 % -> 4 % over 10-3162; B-D collapse only beyond S ~ 300) and the
  training loss is monotone in S; the old pilot's convex-KL runs went uphill at S <= 10 and collapsed by S = 15.
- Blocks A (2-38) and D (90-113) are still not improved by any reweighting of either ensemble: structural misfit.
- The B/C held-out gains, which the old pilot only showed after collapse, now mostly arrive while the ensemble is
  broad: Tris-MD x Tris fold C held-out chi2/N 111 -> 50 at ESS 80 % (S 31.6), 43 at ESS 45 %; fold B 254 -> 146 at
  ESS 79 %. Rule D still takes the extreme S (flag count keeps dropping by 1-2 cells), so a flags-vs-ESS rule is
  the natural next selection question.
- Flags summed over folds, prior / old rule D / new: Tris 106/96/96, Control 106/92/93, Extra 101/86/80,
  Intra 114/98/97. Tris-MD and Control-MD remain indistinguishable. GCI fails in every floor fold as before.
- Rule-D populations (Tris-MD, mean +- fold SD): Compact 0.135 -> 0.19 +- 0.03; Control-MD 0.165 -> 0.30 +- 0.13.
